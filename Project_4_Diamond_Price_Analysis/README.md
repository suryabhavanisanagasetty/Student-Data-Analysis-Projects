# Project 4: Diamond Price Analysis

## Objective

Analyze how different diamond features influence diamond prices using data cleaning, statistical analysis, correlation analysis, outlier detection, and visualization.

## Dataset

Diamonds Dataset

## Tasks Completed

- Imported and explored the Diamonds dataset.
- Checked the dataset shape and column information.
- Identified categorical and numerical features.
- Checked and handled missing values.
- Identified and removed duplicate records.
- Performed descriptive statistical analysis.
- Calculated mean, median, mode, and standard deviation.
- Detected outliers using box plots.
- Treated outliers using the IQR method.
- Analyzed categorical features such as cut, color, and clarity.
- Analyzed numerical features such as carat, depth, table, price, and dimensions.
- Calculated the correlation matrix.
- Analyzed relationships between diamond features and price.
- Compared average prices by cut, color, and clarity.
- Created visualizations to understand feature relationships.
- Prepared business insights and recommendations.

## Visualizations

- Correlation Heatmap
- Carat vs Price Scatter Plot
- Average Price by Cut — Bar Chart
- Average Price by Color — Bar Chart
- Average Price by Clarity — Bar Chart
- Diamond Price Distribution — Histogram
- Average Diamond Price by Carat — Line Chart

## Business Insights

- Carat is an important feature associated with diamond price.
- Larger diamonds generally have higher prices.
- Cut, color, and clarity can also influence diamond pricing.
- Correlation analysis helps identify numerical features related to price.
- Combining carat, cut, color, and clarity can help businesses make better pricing decisions.

The Diamond Price Analysis project explored how different characteristics of diamonds are related to their prices.
