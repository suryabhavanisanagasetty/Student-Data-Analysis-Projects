# Titanic Data Cleaning and Passenger Analysis

## Objective
Clean and analyze the Titanic passenger dataset to understand passenger demographics, survival patterns, and factors affecting survival.

## Tasks
- Load the Titanic dataset using Pandas.
- Explore the dataset.
- Handle missing values.
- Remove duplicate records if any.
- Perform data cleaning and preprocessing.
- Analyze passenger demographics.
- Analyze survival rates based on gender, passenger class, and age.
- Create visualizations to understand survival patterns.
