# Student Performance Analysis

## Project Overview

This project analyzes student performance data to understand academic performance and identify patterns affecting student results.

## Dataset

The dataset contains information about students' Math, Reading, and Writing scores along with demographic and educational factors.

## Analysis Performed

- Total and average score calculation
- Top 10 performing students
- Bottom 10 performing students
- Subject-wise average scores
- Pass vs Fail analysis
- Gender-wise performance analysis
- Test preparation course analysis
- Lunch type analysis
- Parental education analysis
- Race/Ethnicity analysis
- Total score distribution
- Subject score distribution
- Correlation analysis

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Key Findings

- 812 students passed and 188 students failed.
- Reading had the highest average score.
- Mathematics had the lowest average score among the three subjects.
- Most students scored in the middle-to-high range.
- Mathematics, Reading, and Writing scores showed positive relationships.
