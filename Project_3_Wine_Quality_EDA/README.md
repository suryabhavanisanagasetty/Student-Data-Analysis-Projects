# Project 3: Wine Quality Exploratory Data Analysis

## Objective

Explore the factors affecting wine quality using statistical analysis, correlation, data filtering, outlier detection, and visualization.

## Dataset

Wine Quality Dataset

## Tasks Completed

- Explored the dataset using Pandas.
- Checked the number of rows and columns.
- Checked column names and data types.
- Checked and handled missing values.
- Identified and removed duplicate records.
- Performed descriptive statistical analysis.
- Calculated mean, median, and mode.
- Created a correlation matrix.
- Identified highly correlated features.
- Detected outliers using box plots.
- Treated outliers using the IQR method.
- Performed filtering based on wine quality.
- Sorted wines based on quality.
- Created a bar chart for wine quality distribution.
- Created a histogram for alcohol content.
- Created a scatter plot for alcohol content vs wine quality.
- Created a line chart for average alcohol content by wine quality.
- Prepared EDA observations and conclusions.

## Concepts Covered

- Python
- NumPy
- Pandas
- Statistics
- Correlation
- Data Cleaning
- Outlier Detection
- Filtering

- Data Visualization
- Exploratory Data Analysis (EDA)

## Visualizations

- Wine Quality Distribution — Bar Chart
- Alcohol Content Distribution — Histogram
- Alcohol Content vs Wine Quality — Scatter Plot
- Average Alcohol Content by Wine Quality — Line Chart

## Conclusion

The exploratory data analysis provided useful insights into the characteristics of the Wine Quality dataset. Data cleaning, statistical analysis, correlation analysis, outlier treatment, filtering, sorting, and visualization were performed successfully using Python, Pandas, NumPy, and Matplotlib.
